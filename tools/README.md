# tools

`build_static.py` — статические HTML-страницы для поисковиков и `sitemap.xml`.

Сайт читается через docsify (`index.html`, адреса с `#/`). Поисковики считают такие адреса одной страницей, поэтому каждая глава дополнительно собирается в обычный `.html` рядом с `.md`: свой заголовок, описание, канонический адрес и пара RU/EN (по `en/PATHMAP.tsv`).

**После любой правки текста:**

```bash
pip install markdown        # один раз
python3 tools/build_static.py
```

и закоммитить изменившиеся `.html` и `sitemap.xml` вместе с `.md`. Сгенерированные `.html` руками не править.

Новая папка с главами — добавить её в `INCLUDE` в начале скрипта.
