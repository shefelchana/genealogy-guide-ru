# Шаблон: персоны (справочник по людям)

Один файл на весь проект; по одному блоку на человека. Перед каждым новым поиском сначала загляните сюда — что о человеке уже известно.

## [Фамилия Имя Отчество] (годы жизни, как известно сейчас)
- **Варианты имени и фамилии в документах:** (как написано в каждом документе, со ссылкой)
- **Родился:** дата, место — источник (шифр, кадр)
- **Брак:** … — источник
- **Умер:** … — источник
- **Сословие, приписка, занятия, адреса:** … — источник
- **Родители / супруг(а) / дети:** … (статус связи: 🟢 / 🟡 / ⚪ — см. [шкалу статусов](../guide/3-результат/01-доказательность.md))
- **Окружение** (свидетели, компаньоны, соседи, попутчики): …
- **Со слов родных (не проверено):** «…» — кто рассказал, когда
- **Открытые вопросы:** …

— Каждое сведение — с источником. Рассказ родных — отдельной строкой и с пометкой, чей он.
