# Tracing Your Ancestors: A Practical Guide
### Russian Empire, USSR, Jewish families, emigration — a search route, sources, and working with AI

> Version 0.3, October 2026. The guide keeps growing; websites change — check the links.

*This is the English translation of a Russian-language guide. Many of the sources it describes (archives, databases, forums) are in Russian or Ukrainian; where a site is Russian-language, the text says so, and your AI assistant may need to read Russian-language sources for you.*

A guide for people who look for their relatives and information about them in documents: metrical books, revision lists, censuses, newspapers, military and emigration databases, cemeteries and DNA. The main focus is the territory of the former Russian Empire and the USSR (Ukraine, Moldova/Bessarabia, Belarus, Russia, Poland, Lithuania), Jewish genealogy, and emigration to the USA and Europe.

The guide is written for two readers at once: a **human** and their **AI assistant** (Claude, Gemini, ChatGPT and others). The material is drawn from open guides and communities (links to authors and sources are in each section and in [reading/](reading/)) and from the practical experience of a real family research project carried out with the help of AI agents.

> **If you are an AI agent** — start with [AGENTS.md](AGENTS.md) (instructions for the agent) and [llms.txt](llms.txt) (map of the guide). First ask the person about their goal and what is already known about the family.

## The route the guide is built around

```
question → place → source → index → scan → verification → record
```

One question at a time; place matters more than surname; the index first, then the document itself; every find comes with an address and a verbatim quotation. Details — [Search route](guide/1-ai-search/01-search-route.md).

## The essentials in five lines
1. Search by **place** (shtetl, uezd, guberniya), not by surname alone.
2. **A database index is not proof**: look at every record on the scan.
3. Call it "found" only when at least **two independent features** match (not a surname alone).
4. Record **everything, including empty results** — otherwise you will search a second time.
5. Work **slowly** on sites with protection and pass captchas yourself.

## Skills for Claude — how to install

The [skills/](../skills/README.md) folder contains 26 skills: from the first conversation ("I want to find my ancestors") to reading scans, revisions, pogrom databases, cemeteries, DNA and writing the family history. Claude loads the right skill itself when the task fits. Details — [Skills for Claude](guide/1-ai-search/06-skills.md). (The skill files themselves are in Russian.)

**Claude Code — as a plugin** (skills and agents at once):
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```

**Claude Code — manually:** copy the folders from `skills/` into `~/.claude/skills/`, and the files from `agents/` into `~/.claude/agents/`.

**Claude.ai and the Claude app:** on paid plans the plugin can be added there too: Customize → Plugins → Add → Add marketplace, the repository address (for a private repository you need access to it through GitHub). A single skill can also be uploaded without the plugin: zip the whole skill folder (a ZIP containing a folder with `SKILL.md`) and add it under Customize → Skills; skills require code execution to be enabled. Scripts from the `scripts/` folders may not run in the web version (for example, without network access) [unverified].

More details and limitations — [skills/README.md](../skills/README.md).
