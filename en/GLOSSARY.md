# Glossary of terms (Russian → English)

Used for the English version of this guide. On first use in each page, give the English term with the original Russian (transliterated) in parentheses, e.g. "revision lists (*revizskie skazki*)". Keep archive reference codes exactly as written, but expand the archive abbreviation on first use in a page.

## Records and documents
| Russian | English |
|---|---|
| ревизская сказка, ревизия | revision list (*revizskaya skazka*), revision (census for poll tax), e.g. "the 1858 revision (10th revision)" |
| посемейный список | family list (*posemeinyi spisok*) |
| призывной список, рекрутский список | draft list / conscription list; recruit list (pre-1874) |
| метрическая книга, метрика | metrical book (parish/rabbinate vital register); a record from it — "metrical record" |
| казённый раввин | crown rabbi (*kazyonny ravvin*) |
| перепись 1897 года | 1897 All-Russian Census |
| народная перепись | census |
| ЗАГС | ZAGS (Soviet civil registry office) |
| опись, фонд, дело, лист (об.) | inventory (*opis*), fond, file (*delo*), folio / leaf (verso = "ob.") |
| шифр | archival reference (fond-inventory-file, e.g. DAKhmO 226-79-5224) |
| указатель | index |
| скан, кадр | scan, image/frame |
| податная тетрадь | tax register |
| нотариальный акт | notarial deed |
| эвакокарточка | evacuation card |
| следственное дело | investigation file (NKVD/KGB case file) |
| книга памяти | memorial book (book of remembrance) |
| мацева | matzevah (Jewish gravestone) |

|---|---|
| находка | find / finding |
| доказательность | standard of proof |

## Names
Keep Jewish names as they appear in the source in transliteration (Berko, Srul, Leizer, Shlioma); give the Hebrew form when useful (Dov-Ber, Yisrael). Do not anglicise surnames.
