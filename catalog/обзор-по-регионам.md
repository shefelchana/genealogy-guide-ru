# Обзор сайтов по регионам

О чём раздел: навигационная страница — какие генеалогические сайты есть по каждому региону, от России и СССР до Южной Америки и Харбина. Что уже подробно описано в каталоге, здесь дано одной строкой со ссылкой; подробно — только новое. В конце — что осталось непокрытым.

**Как проверяли.** Ссылки проверены 08.10.2026 из одной сети (без VPN), обычными запросами к страницам. Капчи, проверки браузера и входы не обходили: такие сайты помечены «не открылся». Сайт, не открывшийся из одной сети, может открыться из другой — см. [Ложный ноль](../guide/1-поиск-с-ии/09-ложный-ноль.md), раздел 1. Пометки ([стр], [по выдаче], [не проверено]) объяснены в [Словарике](../guide/0-старт/06-словарик.md). Цифры (объёмы баз) — только те, что видны на самих страницах.

## 2. Репрессированные, расстрелянные, ссыльные, депортированные

**Где теперь базы Мемориала.** Мемориал ликвидирован в России по решению суда (конец 2021 — начало 2022) [по выдаче]; его домены не разрешаются (см. начало страницы). Что живо вместо них:

- **[Memsearch](https://memsearch.org/)** — единый поиск по базам Мемориала и других проектов памяти (при участии чешского Gulag.cz). В списке источников — «Жертвы политического террора» (бывшая base.memo.ru), «Сталинские списки», «Топография террора», «Некрополь террора и ГУЛАГа», Сандармох, Левашово, Красный Бор, Пермь-36 и др. Часть источников сама по себе мертва, и неясно, ищется ли она через кэш Memsearch. Бесплатно, без входа; поиск по-русски. [стр: главная, «About», «Sources»; пробный запрос не делали]
- **[«Открытый список»](https://ru.openlist.wiki/)** — более 3,3 млн записей; вход нужен только чтобы дополнять. Подробно — [Война, репрессии, блокада](../guide/2-справочник/12-война-репрессии-блокада.md). [стр]
- **[«Последний адрес»](https://www.poslednyadres.ru/)** — жив, свежие записи июля 2026. Только люди, которым поставили таблички (Москва, Петербург, другие города, Германия), а не все репрессированные. [стр]
- **[«Повернуті імена»](https://search.hdauinp.org.ua/)** (Украина) — см. таблицу ниже. [стр]
- **[e-memory.kz](https://e-memory.kz/)** (Казахстан) — см. таблицу ниже. [стр]
- **[doc.arhiva.gov.md](http://doc.arhiva.gov.md/)** (Молдова) — см. таблицу ниже. [стр]

### Харбин, Китай, Шанхай

Единой базы нет. Основа — доклад 2006 года на конференции IAJGS (опубликован на сайте JRI-Poland): устарел, но источники названы конкретно [стр].

- **CAHJP** (Иерусалим): списки HIAS из Шанхая — 8528 семей; **YIVO** RG 243 (Шанхай 1946–1948) и RG 352 (HIAS на Дальнем Востоке 1918–1955); **NARA** RG 263, лента M1750 — архив Шанхайской муниципальной полиции 1894–1949 (списки беженцев, справки о русских евреях 1933–1940).
- **Кладбище Хуаншань** в Харбине: 515 имён — в JOWBR и на jewsofchina.org (кириллицей).
- **jewsofchina.org** — ассоциация выходцев из Китая (Игуд Йоцей Син, Тель-Авив), разделы по общинам [стр]; **KehilaLinks Harbin** и **Sino-Judaic Institute** — открываются, не прочитаны.
- **БРЭМ** — справочник Хабаровского госархива по Бюро по делам российских эмигрантов в Маньчжурии (gakhkk.khabkrai.ru/projects/brem/) [по выдаче; сайт не соединился].
- **ВГД**, темы «Списки харбинцев и жителей станций КВЖД», «Эмиграция из Харбина» (forum.vgd.ru/614/) — карточки эмигрантов Шанхайской полиции, справочники КВЖД, списки умерших [по выдаче].

### ЮАР, Австралия, Новая Зеландия

- **SA Jewish Rootsbank** — уже в [сша-и-эмиграция.md](сша-и-эмиграция.md).
- **eGGSA** (eggsa.org) — онлайн-отделение Генеалогического общества ЮАР: церковные и кладбищенские книги, пассажиры, избиратели 1925–1931, фото надгробий; полный доступ по платному членству; еврейских баз нет [стр].
- **National Archives of Australia** — уже в [сша-и-эмиграция.md](сша-и-эмиграция.md); по выдаче есть путеводитель «Safe haven» по еврейским документам. Trove, Papers Past, Archives NZ — не проверены.

### Турция: Константинополь и эвакуация 1920 года

Сводного списка эвакуированных из Крыма в Константинополь не нашлось.
- **Hoover Institution, коллекция Врангеля** (OAC, oac.cdlib.org) — 1916–1929: эвакуация из Крыма, расселение беженцев в Турции и Европе; 164 коробки, микрофильм — 220 катушек, часть оцифрована. Поимённых списков в описании нет [стр].
- **Архив ООН в Женеве, «Нансеновский фонд»** — дела Верховного комиссара Лиги Наций по делам беженцев 1919–1947 [по выдаче; сайт ответил 429].

## Что осталось непокрытым

**Регионы**
- **Беларусь:** все сайты (niab.by, nlb.by, archives.gov.by, narb.by) не открылись; описание держится на выдаче.
- **Азербайджан, Армения, Таджикистан, Туркмения, Кыргызстан, Узбекистан** (кроме Ташкентской базы эвакуированных): ни проверенных фондов, ни баз. Настоящий адрес архива Армении не установлен.
- **Грузия:** открылась только главная архива; «Сталинские списки» — нет.
- **Федеральные и столичные архивы России** (ГАРФ, РГВА, ЦАМО, РГВИА, Мосгорархив, ЦГА СПб): ни один сайт не открылся.
- **Румыния, Словакия, Болгария, Греция, Сербия, Дания, Финляндия:** проверка браузера, нет соединения или не проверялись.
- **Канада:** Library and Archives Canada — за проверкой браузера; Ontario Jewish Archives не открылся.
- **Колумбия, Перу, Венесуэла, Парагвай, Боливия, Панама:** только перечни еврейских организаций в старых справочниках, архивов с поиском нет.
- **Мексика и Чили:** только справочные описания, поиска по прибытию нет.
- **Япония (Кобе), Индия, Иран** (маршруты 1939–1945), **Сибирь и Дальний Восток** как место ссылки или бегства — не искали.
- **Турция:** единого списка беженцев 1920 года нет; только косвенные следы (Нансеновский фонд, Hoover).

**Группы людей и источники**
- **Депортации народов СССР** и **спецпоселенцы по областям** — единых проверяемых баз нет; подтвердились только Казахстан, Украина, Молдова, Латвия.
- **Раскулаченные:** только категория в e-memory.kz и книги «Реабілітовані історією»; из российских региональных баз найдена «Раскулаченные. Свердловская область» (79 402 записи, см. [Православные и крестьяне](../guide/2-справочник/21-православные-и-крестьяне.md), раздел о XX веке); единой базы по стране нет.
- **Дела в архиве СБУ:** сайт не открылся, процедура — только по статье 2018 года.
- **Литовские, латвийские, эстонские базы репрессированных:** кроме латвийских «депортированных» в Raduraksti, не открылись.
- **Работает ли поиск** у Memsearch, «Повернутих імен», e-memory.kz, doc.arhiva.gov.md: открыты главные страницы и описания, пробные запросы по фамилии не делали.
- **Не пересмотрены:** Chronicling America, Fold3, Trove, Papers Past, ICRC, JDC Archives (Names Index).

Знаете один из этих регионов — давайте соберём по нему раздел вместе: [Чего нет в руководстве](../guide/0-старт/07-чего-нет.md), «Давайте собирать вместе».
