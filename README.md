# Поиск предков: практическое руководство
### Российская империя, СССР, еврейские семьи, эмиграция — маршрут поиска, источники, работа с ИИ

> Версия 0.4, октябрь 2026 г. Руководство пополняется; сайты меняются — проверяйте ссылки.

Руководство для тех, кто ищет своих родных и сведения о них по документам: метрическим книгам, ревизиям, переписям, газетам, военным и эмиграционным базам, кладбищам и ДНК. Территория — бывшая Российская империя и СССР (Украина, Молдова/Бессарабия, Беларусь, Россия, Польша, Литва) и эмиграция в США и Европу.

**Честно о фокусе.** Руководство выросло из опыта поиска еврейских семей Подолии, Киевщины и Бессарабии, и глубже всего разобрано именно это. Маршрут поиска, проверка находок и ведение записей годятся для любых семей. Но православные и крестьянские линии, ранние ревизии I–IV (1719–1782), исповедные ведомости, консистории, нееврейские кладбища пока освещены мало: что есть — в [Документах Российской империи и СССР](guide/2-справочник/01-документы-ри-и-ссср.md), в разделе о [российских областных архивах и ЕАИС](catalog/сканы-архивных-дел.md) и в [русскоязычных ресурсах](catalog/русскоязычные-ресурсы.md); общие ресурсы — в [каталоге сайтов](catalog/README.md), сообщество по нееврейской генеалогии — форум ВГД ([Группы и сообщества](reading/группы-и-сообщества.md)).

Руководство написано для двух читателей сразу: для **человека** и для его **ИИ-помощника** (Claude, Gemini, ChatGPT и др.). Материал собран из открытых руководств и сообществ (ссылки на авторов и источники — в каждом разделе и в [reading/](reading/README.md)) и из практического опыта реального семейного исследования, проведённого с помощью ИИ-агентов в **Claude Code**. Но уметь работать с агентами не обязательно: начать можно с одной проверки в браузере с ИИ-плагином — см. [Три уровня](guide/0-старт/00-три-уровня.md).

**Честно о фокусе (коротко):** упор на еврейскую генеалогию; что описано мало — в разделе [Чего нет в этом руководстве](guide/0-старт/07-чего-нет.md).

## С чего начать

- **Хочу просто попробовать** — [Три уровня](guide/0-старт/00-три-уровня.md): одна проверка на одном родственнике прямо в браузере, 15 минут, без установки и файлов. Там же — как дорасти до проекта с агентами.
- **Я только начинаю** — [Быстрый старт](guide/0-старт/01-быстрый-старт.md): одна страница, первый час работы. Незнакомые слова — в [Словарике](guide/0-старт/06-словарик.md).
- **Я застрял** — [Сценарии: что делать, если…](guide/1-поиск-с-ии/07-сценарии.md).
- **Я ИИ-агент** — начните с [AGENTS.md](AGENTS.md) (инструкция для агента) и [llms.txt](llms.txt) (карта руководства). Сначала спросите человека о цели и о том, что уже известно о семье.

Всё руководство устроено по одному маршруту: **вопрос → место → источник → индекс → скан → проверка → запись** — подробно в [Маршруте поиска](guide/1-поиск-с-ии/01-маршрут-поиска.md).

## Как читать

Начало читайте подряд: разделы стоят в порядке работы. **Маршрут поиска, Проверка результата и Сценарии** лежат в части 1, но они для всех, а не только для тех, кто работает с ИИ: это общий порядок поиска и выход из тупиков. Справочник (часть 2) открывайте по мере надобности: в каждом разделе есть врезка «Как попросить ИИ». Пометки в квадратных скобках (**[стр]**, **[по выдаче]**, **[не проверено]**) показывают, насколько проверено сведение, — что они значат, сказано в [Словарике](guide/0-старт/06-словарик.md), в конце.

## Навыки для Claude — как установить

В папке [skills/](skills/README.md) — 26 навыков: от первого разговора («хочу найти предков») до чтения сканов, ревизий, баз погромов, кладбищ, ДНК и написания истории семьи. Claude подгружает нужный навык сам, когда задача подходит. Подробно — [Навыки для Claude](guide/1-поиск-с-ии/06-навыки.md).

**Claude Code — плагином** (навыки и агенты сразу):
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```

**Claude Code — вручную:** скопируйте папки из `skills/` в `~/.claude/skills/`, файлы из `agents/` — в `~/.claude/agents/`.

**Claude.ai и приложение Claude:** на платных планах плагин можно добавить и там: меню Customize → Plugins → Add → Add marketplace, адрес репозитория `shefelchana/genealogy-guide-ru`. Отдельный навык можно загрузить и без плагина: заархивируйте папку навыка целиком (ZIP, внутри папка с `SKILL.md`) и добавьте в Customize → Skills; для навыков нужно включённое выполнение кода. Скрипты из папок `scripts/` в веб-версии могут не запускаться (например, без доступа к сети) [не проверено].

Подробнее и ограничения — [skills/README.md](skills/README.md).
