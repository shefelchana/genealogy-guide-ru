# Поиск предков: практическое руководство
### Российская империя, СССР, еврейские семьи, эмиграция — маршрут поиска, источники, работа с ИИ

> ⚠️ Черновик, собирается. Состояние на октябрь 2026 г. Сайты меняются — проверяйте ссылки.

Руководство для тех, кто ищет своих родных и сведения о них по документам: метрическим книгам, ревизиям, переписям, газетам, военным и эмиграционным базам, кладбищам и ДНК. Основной фокус — территория бывшей Российской империи и СССР (Украина, Молдова/Бессарабия, Беларусь, Россия, Польша, Литва), еврейская генеалогия и эмиграция в США и Европу.

Руководство написано для двух читателей сразу: для **человека** и для его **ИИ-помощника** (Claude, Gemini, ChatGPT и др.). Материал собран из открытых руководств и сообществ (ссылки на авторов и источники — в каждом разделе и в [reading/](reading/)) и из практического опыта реального семейного исследования, проведённого с помощью ИИ-агентов.

> **Если вы ИИ-агент** — начните с [AGENTS.md](AGENTS.md) (инструкция для агента) и [llms.txt](llms.txt) (карта руководства). Сначала спросите человека о цели и о том, что уже известно о семье.

## Маршрут, по которому устроено руководство

```
вопрос → место → источник → индекс → скан → проверка → запись
```

Один вопрос за раз; место важнее фамилии; сначала указатель, потом сам документ; каждая находка — с адресом и дословной цитатой. Подробно — [Маршрут поиска](guide/1-поиск-с-ии/01-маршрут-поиска.md).

## Главное в пяти строках
1. Ищите по **месту** (местечко, уезд, губерния), а не только по фамилии.
2. **Индекс базы — не доказательство**: каждую запись смотрите на скане.
3. «Нашёл» — только когда сходятся минимум **два независимых признака** (не одна фамилия).
4. Записывайте **всё, включая пустые результаты**, — иначе будете искать второй раз.
5. Работайте **медленно** на сайтах с защитой и проходите капчи сами.

## Навыки для Claude — как установить

В папке [skills/](skills/README.md) — 26 навыков: от первого разговора («хочу найти предков») до чтения сканов, ревизий, баз погромов, кладбищ, ДНК и написания истории семьи. Claude подгружает нужный навык сам, когда задача подходит. Подробно — [Навыки для Claude](guide/1-поиск-с-ии/06-навыки.md).

**Claude Code — плагином** (навыки и агенты сразу):
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```

**Claude Code — вручную:** скопируйте папки из `skills/` в `~/.claude/skills/`, файлы из `agents/` — в `~/.claude/agents/`.

**Claude.ai и приложение Claude:** на платных планах плагин можно добавить и там: меню Customize → Plugins → Add → Add marketplace, адрес репозитория (для закрытого репозитория нужен доступ к нему через GitHub). Отдельный навык можно загрузить и без плагина: заархивируйте папку навыка целиком (ZIP, внутри папка с `SKILL.md`) и добавьте в Customize → Skills; для навыков нужно включённое выполнение кода. Скрипты из папок `scripts/` в веб-версии могут не запускаться (например, без доступа к сети) [не проверено].

Подробнее и ограничения — [skills/README.md](skills/README.md).
