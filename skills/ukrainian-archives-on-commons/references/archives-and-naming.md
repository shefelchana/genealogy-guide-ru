## 2. Образцы имён файлов

| Что | Образец |
|---|---|
| дело, «точечная» форма | `ДАХмО 227-1-137. 1800-1804. Про порушення прав міщан м. Бар ….pdf` |
| дело, форма с дефисом | `ДАХмО - 226-80-639 Відомості про … 1816-1820.pdf` |
| дело с годом в скобках | `ДАЛО Р-3321-1-10 Книга державної реєстрації шлюбу (1940).pdf` |
| дело с буквой | `ЦДІАК 127-1012-1197а. 1801. Метричні книги церков Уманського повіту.pdf` |
| бумажная опись | `ДАХмО фонд 227 опис 1.pdf`; встречаются приписки вроде «поновлено» |
| сводный каталог | `ЗВЕДЕНИЙ КАТАЛОГ МЕТРИЧНИХ КНИГ, ЩО ЗБЕРІГАЮТЬСЯ В ДЕРЖАВНИХ АРХІВАХ УКРАЇНИ міжархівний довідник. Т. N.pdf` |
| каталог одного архива | `Державний архів Одеської області. Зведений каталог метричних книг. Випуск 1. ….pdf` |

В API пробелы и подчёркивания в именах равнозначны; в ответе `allimages` имена приходят с подчёркиваниями.

## 3. Бумажные описи на Commons

- Сплошные серии описей: по ДАХмО — около тысячи файлов, по ДАВіО — около двухсот (2026). Список описей фонда: `list=allimages`, `aiprefix=<АРХИВ> фонд <N> опис`.
- У крупных фондов опись разбита на тома (`опис 1 том 1–5`) и дополнения (`1д`, `2д` …) — проверяй все.
- Не все описи оцифрованы: например, у ф. 226 ДАХмО на Commons нет описей 1–30. Их дела доступны только в архиве — это ограничение источника, а не «дел нет».
- Опись в сотни МБ целиком часто не отдаётся (HTTP 429); читай её постранично миниатюрами шириной 3840 px.

## 4. Вікіджерела: структура пространства «Архів:»

- `Архів:Архіви` — перечень архивов.
- `Архів:<АРХИВ>` — фонды архива; `Архів:<АРХИВ>/Р` — советские фонды (удобно искать «метричні книги» для ЗАГС).
- `Архів:<АРХИВ>/<фонд>/<опис>` — роспись описи: шаблон с названием, годами и ссылкой на файл бумажной описи в примечаниях; таблица дел.
- `Архів:<АРХИВ>/<фонд>/<опис>/<справа>` — подстраница дела со ссылкой на файл Commons.
- ⚠️ Роспись — выборка (бывает 3 % дел описи) и иногда ошибается в заголовках. Для отрицательных выводов не годится.

## 6. Где ещё искать шифр по Украине

- Міжархівний пошуковий портал (searcharchives.net.ua) — 13 архивов, поиск по названиям фондов и дел, аннотациям и указателям.
- archium-сайты архивов (например, archium.cdiak.archives.gov.ua, archium.dahmo.gov.ua) — поиск по заголовкам дел; покрытие неполное.
- FamilySearch — плёнки метрик ЦДІАК, ЦДІАЛ и областных архивов (навык `searching-familysearch-films`).
