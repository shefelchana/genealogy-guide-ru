## Проверка перед подачей

- [ ] Нет пропущенных звеньев (брак родителей по материнской линии — тоже звено)
- [ ] Каждое расхождение имени закрыто документом
- [ ] Справки с печатью, без исправлений
- [ ] Апостиль — в стране выдачи; перевод — после него, признанный переводчик
- [ ] Справка о несудимости в пределах срока программы
- [ ] Учтены законы о потере гражданства у опорного предка
- [ ] Ни одно звено не держится только на онлайн-дереве
