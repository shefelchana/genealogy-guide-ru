# Навыки (skills) для Claude

Порядок — по шагам маршрута поиска, тот же, что в [руководстве](../guide/1-поиск-с-ии/06-навыки.md).

**Начало и организация работы**

| Навык | Когда срабатывает |
|---|---|
| `genealogy-intake` | первый разговор, файлов проекта ещё нет: «хочу найти предков», что известно, цель, файлы проекта, первый вопрос и план |
| `organizing-genealogy-research` | ход работы в проекте, где файлы уже есть: один вопрос, поиск по своим файлам, запись находок, «доказано?», закрытие направления |
| `search-logic-navigator` | развилки поиска: не нашёл, нашлось много однофамильцев, индекс спорит со сканом, тупик |
| `orchestrating-genealogy-agents` | работа поручена агентам: как разбить поиск на задания, шаблон задания, темп и капчи, приём и проверка отчётов |
| `research-session-handoff` | конец сессии, сжатие контекста, возобновление: «сохрани всё», «продолжи с того места», файл «Продолжать отсюда», состояние агентов |

**Место и источник**

| Навык | Когда срабатывает |
|---|---|
| `identifying-places` | найти местечко или село, уезд и губернию в нужный год, смены границ и названий |
| `ukrainian-archives-on-commons` | дела украинских архивов на Wikimedia Commons и описи на Вікіджерелах |
| `soviet-era-records` | война, эвакуация, блокада, репрессии, советский ЗАГС — базы по регионам |
| `tracing-emigrants-to-origin` | от документов США/Европы к местечку |
| `searching-pogrom-records` | погромы 1918–1922 (с конца 1917): базы Липес и «Ам а-Зикарон», ДАКО Р-3050, получатели помощи, сироты, беженцы |
| `researching-jewish-cemeteries` | где похоронен, базы захоронений, чтение мацевы, перевод еврейской даты |

**Индекс и поиск по базам**

| Навык | Когда срабатывает |
|---|---|
| `using-community-surname-indexes` | сначала фамильный указатель (j-roots, JewishGen, JGFF), потом листание; реестр непрочитанных разделов |
| `searching-jewishgen` | базы JewishGen: поиск, лимит 50 строк, чтение полей, переход к скану |
| `searching-familysearch-films` | плёнки FamilySearch: каталог → DGS → кадр, границы книг, темп и капчи |
| `searching-yandex-archives` | Яндекс Поиск по архивам: операторы, написания, как читать результат |
| `searching-nli-jewish-press` | еврейские газеты в Национальной библиотеке Израиля |

**Скан и чтение**

| Навык | Когда срабатывает |
|---|---|
| `reading-archive-scans` | читать оцифрованные дела (PDF с Commons и др.), оценить качество скана, карта тома |
| `tracing-revision-records` | идти вглубь по ревизским сказкам 1795–1858 |
| `reading-hebrew-yiddish-sources` | надгробия, ивритская часть метрик, подписи, газеты на идише; соответствия имён |
| `dating-old-photos` | датировать старую фотографию по паспарту, одежде, ателье |
| `interpreting-jewish-family-photos` | что говорит еврейская семейная фотография об укладе и событии: признак → гипотеза → документ |

**Проверка и результат**

| Навык | Когда срабатывает |
|---|---|
| `verifying-genealogy-findings` | проверить находку, понять, значит ли что-то «не нашёл», варианты написаний, полнотекст genealogyindexer |
| `reconstructing-family-clusters` | нашёл отца и детей — собрать пакет документов на семью и свести однофамильцев в одно дерево |
| `dna-matches-endogamy` | разбор ДНК-совпадений при эндогамии (еврейские семьи и др.) |
| `citizenship-by-descent-dossier` | собрать цепочку документов для гражданства по происхождению |
| `writing-family-history` | превратить находки в читаемый текст для родных |

## Установка в Claude Code
Как плагин (навыки + агенты):
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```
Вручную: скопировать папки из `skills/` в `~/.claude/skills/`, файлы из `agents/` — в `~/.claude/agents/`.

## Claude.ai / приложение Claude
На платных планах плагин можно добавить и там: Customize → Plugins → Add → Add marketplace, адрес репозитория `shefelchana/genealogy-guide-ru`. Отдельный навык можно загрузить без плагина: ZIP с папкой навыка (внутри `SKILL.md`) → Customize → Skills; нужно включённое выполнение кода. Скрипты из `scripts/` в веб-версии могут не запускаться [не проверено].

## Ограничения
- Навыки не проходят капчи и не входят в аккаунты — это делает человек.
- Сайты меняются: приёмы проверены в сентябре–октябре 2026 г.
