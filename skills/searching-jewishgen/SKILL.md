# JewishGen: поиск и правильное чтение индексов

## Доступ
- Регистрация бесплатная; без входа поиск частично работает, но подробные записи открываются под аккаунтом.
- Базы разбиты по регионам (Ukraine, Romania — сюда входит Бессарабия, Lithuania, Belarus…) и темам (JOWBR — кладбища, Holocaust, KehilaLinks, Communities/Gazetteer).

## Как искать
1. **Фамилия — фонетически** (Daitch-Mokotoff) для первого прохода; потом **точно** — чтобы отсечь шум.
2. **Имя — «начинается с»** (Ber… поймает Берко, Берл, Бер-Ицко).
3. **Город** — отдельным полем; для больших выдач — обязательно.
4. «Любое поле» — для отчеств и имён родителей («Duvid» в любом поле).

## Лимит выдачи
Показывается только **первая страница (~50 строк)** по каждому набору данных. Если «276 matching records», а видно 50 — сужайте: город, годы, имя, тип записи. Иначе пропустите нужное.

## Как читать строку
- В ревизиях одна семья = несколько строк (глава, жена, дети); возраст «прошлой ревизии | этой».
- В браках поля отца/матери бывают в одной ячейке с разделителями («Duvid////») — **первая позиция может относиться к жениху, а не к невесте**. Сверять по скану.
- Колонки «Archive/Fond», «Microfilm», «Image/Page» — адрес оригинала. **Каждую ключевую запись открывать на скане** (FamilySearch, data.jewishgen.org).
- Даты: возможен сдвиг старого/нового стиля и ошибки индексатора (пример: индекс «8.VI», на скане «15 июня ст. ст. = 7 тамуза»).
- Приписка может выглядеть как фамилия: «Rashkovsky meshch.» = мещанин Рашкова.

## Что полезно помимо имён
- Ташкентские карточки эвакуированных 1942 г. (отчество, профессия, адрес до войны, скан карточки).
- JOWBR — годы жизни и фото надгробий (на иврите — имя отца).
- KehilaLinks — страницы местечек, ссылки на источники.
- ViewMate — волонтёры помогают прочитать и перевести скан.
- JGFF — кто ещё ищет ту же фамилию и местечко.

## Записать
Набор данных, запрос (как именно искали), число найденных, строка дословно, ссылка на скан, результат проверки по скану.
