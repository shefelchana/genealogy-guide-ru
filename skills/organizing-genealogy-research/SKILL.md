# Как вести генеалогическое исследование с ИИ

## Файлы проекта (создать в начале)
- `ДОСЬЕ.md` — журнал находок: дата, источник с шифром, дословная цитата, кроп, оценка.
- `ПЕРСОНЫ.md` — справочник по людям (включая строку «окружение»: свидетели, компаньоны, соседи, попутчики).
- `ГИПОТЕЗЫ.md` — основания / слабые места / как проверить / статус 🟢🟡🔴.
- `ЖУРНАЛ-ПОИСКОВ.md` — каждый поиск, включая пустые, с охватом.
- `ИСТОЧНИКИ.md` — реестр: архив, фонд-опись-дело, где скан, что прочитано.
- `ИСТОРИЯ.md` — связный текст для родных.
- `ПРОДОЛЖАТЬ-ОТСЮДА.md` — текущее направление, работающие задачи, следующие шаги.

## Начало раунда
1. Прочитать `ПРОДОЛЖАТЬ-ОТСЮДА.md`.
2. Сформулировать **один вопрос** с критерием ответа и лимитом времени.
3. **Поиск по своим файлам** (фамилия, место, имя) — чтобы не переоткрывать найденное.
4. Коротко сказать пользователю: что ищем, на что опираемся, каким методом.

## Задание агенту (проверяемое)
- Вставить в задание **уже известное** дословно и список **отведённых двойников**.
- Дать **контрольную запись** — заведомо существующую, чтобы проверить чтение.
- Требовать: «пиши только то, что видишь»; на каждое попадание — кадр/лист + цитата + кроп; неуверенное помечать; **журнал покрытия**; честное «не найдено».
- Отдельная папка для файлов каждого агента.
- «**Других агентов не запускай.** Если объём слишком велик — верни план и остановись».
- **Один сайт — один исполнитель**; темп задать явно; при капче — остановиться, ничего не нажимать.
- Капчи, пароли, отправку сообщений и платежи делает только человек.

## Получение отчёта
1. **Сверить каждую находку по кадру самому** (агенты видят ожидаемое).
2. Проверить, что массовый проход не «пустой из-за ошибок» (были ли ответы 403/капча).
3. Сразу записать: ДОСЬЕ + ПЕРСОНЫ + статус в ГИПОТЕЗЫ + строка в ЖУРНАЛ.

## Перед словом «доказано»
- Поиск разумно полный (названы охват и написания).
- Источник процитирован с шифром.
- Есть **второе независимое** совпадение (индекс и скан одной записи — это одно свидетельство).
- Противоречия разобраны явно.
- Для косвенных выводов — письменное обоснование.
В онлайн-дерево — только подтверждённое.

## Закрытие направления / конец сессии
- Итог двумя слоями: факт с шифром + абзац для семейной истории.
- Обновить `ПРОДОЛЖАТЬ-ОТСЮДА.md` (что работает, что ждёт человека — капчи, VPN, решения).
- Записать уроки (что сработало, что тормозило) — в отдельный файл методики.

См. также: `verifying-genealogy-findings`, `reading-archive-scans`.
