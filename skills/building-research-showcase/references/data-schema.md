# Схема данных витрины

Все ключи необязательны: раздел рисуется, только если для него есть данные. Текстовые поля — простой текст; можно `**жирный**` и `*курсив*`. HTML не вставлять. Полный пример — `assets/example-shapiro.json`.

Уровни: `🟢` доказано документом, `🟡` вероятно, есть пробел, `⚪` не решено, `💭` версия / семейная память, `🔴` опровергнуто, `"zero"` — ноль с охватом (только в каталоге источников).

## Общие (файл координатора `00-meta.json`)

```json
{
  "lang": "ru",                       // "ru" или "en" — язык подписей интерфейса
  "title": "Витрина исследования: …",
  "description": "одна фраза для поисковиков",
  "kicker": "строка над заголовком",
  "lead": "абзац под заголовком",
  "banner": "плашка: учебный пример / только для семьи",
  "footer": "строка внизу",
  "lines": [{"id": "a", "name": "Шапиро"}],       // до 5; цвета по порядку: синий, оранжевый, бирюзовый, фиолетовый, розовый
  "sections": {"sources": {"h": "свой заголовок", "p": "своя подводка", "aside": [{"h": "Где сделать", "text": "…"}]}}
}
```
`sections` — по желанию: переопределить заголовок, подводку и добавить блоки «aside» под раздел. Имена разделов: `methods, sources, people, profile, tree, map, dna, comparisons, story, surnames, library`.

## Каталоги (`building-research-catalogs`)

```json
"sources": [{"ref": "ДАЖО 67-3-220", "year": 1899, "type": "метрики", "who": "Наум Ицкович",
             "gave": "рождение в Бердичеве; мать «Хая»", "level": "🟢", "line": "a"}],
"people":  [{"name": "Наум Ицкович Шапиро", "years": "1899–1966", "role": "Бердичев → Москва · прадед",
             "line": "a", "level": "🟢", "initials": "НШ"}],      // level — уровень главной связи
"profile": {"name": "…", "initials": "НШ", "kicker": "Прадед · линия Шапиро",
            "facts": [["Родился", "1899, Бердичев 🟢"]],
            "timeline": [{"year": "1899", "text": "…", "source": "шифр", "level": "🟢"}],
            "family": [{"name": "Ицко Лейбович", "note": "отец"}],
            "sources": [{"tag": "ДАЖО", "text": "67-3-220 — метрика", "level": "🟢"}],
            "questions": [{"text": "…", "level": "🟡"}]},
"library": {"tree": "многострочный текст схемы папок", "naming": "правило имени файла",
            "example": "пример имени", "card": [["шифр", "…"], ["статус", "…"]]}
```
`type` — короткие одинаковые слова (по ним фильтр): метрики, ревизии, переписи, ЗАГС, военные, эвакуация, справочники, суд и учёт.

## Дерево и места (`rendering-family-tree`)

```json
"pedigree": {"generations": [
   [{"name": "Мария", "sub": "ШАПИРО · 1991", "line": "none"}],
   [{"name": "отец", "sub": "…", "line": "a"}, {"name": "мать", "sub": "…", "line": "c"}],
   [ …4… ], [ …8… ]]},                 // по Аненталю: в поколении g позиции 2i и 2i+1 — отец и мать человека i; null = «?»
"ladder": {"title": "Лестница линии …", "steps": [{"name": "…", "note": "годы · документ", "level": "🟢"}], "aside": "текст справа"},
"places": {"ber": {"name": "Бердичев", "lat": 49.9, "lon": 28.6, "info": "кто и когда", "label": "l", "dy": 10}},
"routes": [{"line": "a", "path": ["ber", "zhi", "ode"], "bend": -0.24}],     // bend: изгиб дуги, знак — в какую сторону
"offmap": "↘ Ташкент (эвакуация) — за пределами схемы"
```
Рисуются первые 4 поколения. `label: "l"` — подпись слева от точки; `dy` — сдвиг подписи по вертикали.

## Доказательства (`building-evidence-matrix`)

```json
"cycle":   [{"title": "Вопрос", "text": "…"}],          // 7 шагов одного прохода
"methods": [{"title": "Ноль с охватом", "note": "что это", "example": "пример из проекта"}],
"comparisons": [{"title": "Мать Наума", "columns": ["Имя", "Источник", "Вес"],
                 "rows": [["Хая", "метрика 1899", "🟢 запись в момент события"]],
                 "verdict": "Вероятно 🟡: …", "wide": false}]
```

## ДНК (`checking-dna-against-tree`)

```json
"dna": {"caption": "кто сдал, компания, дата модели",
        "bars": [{"name": "Восточноевропейцы", "value": 46.3, "line": "e", "expected": 50, "sd": 4.7, "alt": 75}],
        "verdict": "вопрос, ожидание, результат, вывод с уровнем, оговорки", "scale": 80}
```
`expected` и `sd` — ожидание по документам и разброс; `alt` — ожидание, если легенда верна; `scale` — правая граница шкалы (по умолчанию считается сама).
