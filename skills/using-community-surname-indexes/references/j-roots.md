# Форум j-roots («Еврейские корни»): как брать фамильные указатели

Проверено 07.10.2026. Движок форума — phpBB.

## Что там есть

- **Темы по местечкам и уездам** (например, «СКВИРА и СКВИРСКИЙ уезд»). В первых постах волонтёры расписывают дела: «1858 год. Ревизская сказка евреев Сквирского уезда. Госархив Киевской области. Фонд 280, опись 2, дело 1490» → ссылка на PDF → «кадры 82–128 — ПАВОЛОЧЬ» → под спойлером список фамилий раздела. Так устроены списки Краковского, Финкельштейна и других составителей.
- **Темы «ГАКО, фонд 280_ревизские сказки»**, «ГАКО, разные фонды, поиск и находки», «Перепись 1897» по уездам — сводные указатели по фондам.
- **Фамильный навигатор** — `viewtopic.php?f=20&t=1384` (ссылка «Фамильный указатель» в шапке форума): оглавление **фамильных тем**, которые открывали сами исследователи («что знаем, что ищем»). Это не указатель к делам, а указатель к людям, которые уже искали фамилию.
- Тема «архивные документы, которые участники форума просят отснять» — что отснято недавно и по какому шифру.

## Доступ

| Что | Без входа | Проверено |
|---|---|---|
| `viewtopic.php?t=…`, `viewtopic.php?p=…` | открывается | да, 07.10.2026 |
| `search.php?keywords=…` | **«Извините, но вам запрещено пользоваться поиском»** | да, 07.10.2026 |
| ссылки из выдачи поиска с `hilit=`/`sid=` | бывает 403; прямой адрес темы открывается | по журналу работы |

- Поиск по форуму работает только под аккаунтом. Вход делает человек в своём браузере; агент может читать результаты в его вкладке, ничего не публикуя.
- Без входа: поисковик с ограничением на домен, например запрос «Паволочь ревизия 1858 фонд 280» с фильтром `forum.j-roots.info` — так находятся темы и страницы тем (проверено 07.10.2026).
- Под аккаунтом форма поиска — `search.php?keywords=ФАМИЛИЯ&terms=all&sf=all&sr=posts` (все слова, по тексту и заголовкам, вывод сообщениями). Ищи каждую форму фамилии отдельно и со звёздочкой (`Фамил*`).
- Сертификат сайта у части клиентов не проходит проверку — `curl -k` допустим **только** для чтения публичных страниц без входа: не передавай с таким запросом куки, пароли и формы. Если сайт уводит на страницу блокировки или не отвечает из-за сети (VPN, гео-ограничения) — **не обходи**, сообщи человеку.

## Как забрать пост целиком

Списки фамилий спрятаны в спойлеры «► Показать» (`div.spoilcontent` со стилем `display:none`). **innerText браузера и «копировать текст» их пропускают**, и тогда фамилии «нет» там, где она есть.

1. Сохрани страницу HTML:
   ```
   curl -sk -A "Mozilla/5.0 ... Chrome/129.0 Safari/537.36" \
     "https://forum.j-roots.info/viewtopic.php?p=NNNNNN" -o post-NNNNNN.html
   ```
   В браузере — `textContent` или `outerHTML` нужного `div.post`, а не innerText.
2. Разбери локально:
   ```
   python3 scripts/forum_post_index.py post-NNNNNN.html Фамилия Вариант --loose
   ```
   Скрипт печатает пост, строку, ближайший выше заголовок документа (фонд-опись-дело), раздел (строка заглавными — обычно местечко или волость) и ближайшую выше ссылку на PDF.
3. **Сверь глазами**: заголовок выбран автоматически. Один пост часто содержит 5–15 дел подряд (1795, 1816, 1850, 1858, 1875, 1888…), и фамилия встречается в нескольких.
4. Страница темы отдаёт по 10–20 постов; длинная тема продолжается на `&start=20`, `&start=40`.

## От поста к скану

- Ссылки на PDF в постах обрезаны в видимом тексте («upload.wikimedia.org/wikipedia/ … .pdf»); полный адрес — в атрибуте `href` (скрипт берёт его сам и раскодирует).
- Если ссылки нет: найди файл через API Commons (`list=search`, `srnamespace=6`). Файлы названы по-разному («ДАКО 280-2-365. 1816…», «ГАКО 280 1490 1491 1858 Сквирский уезд», «1858 год. Ревизская сказка евреев Сквирского уезда»), поэтому ищи **словами**, а не одной строкой шифра: `280 1490 1858` находит файл, `intitle:"280-2-1490"` — нет (проверено 07.10.2026). Затем опись дела на uk.wikisource (`Архів:ДАКО/280/2`). Навык `ukrainian-archives-on-commons`.
- Номера «кадров» в посте — страницы PDF; номера листов дела — на самом скане. В досье пиши оба.

## Чего указатель не даст

Имён, возрастов, номеров семей и листов. Только «фамилия есть в этом разделе этого дела». Остальное — по скану.
