# Словарик терминов и пометок

О чём раздел: короткие объяснения слов, которые встречаются в руководстве на каждом шагу, — по одной-две строки. Плюс что значат служебные пометки в квадратных скобках и цветные значки статусов.

---

## Документы и архивы

| Термин | Что это |
|---|---|
| **Шифр** (архивный) | адрес документа в архиве: **фонд — опись — дело — лист**. Например, «ДАХмО 226-79-5224, л. 12» — архив Хмельницкой области, фонд 226, опись 79, дело 5224, лист 12. Подробно — [Документы РИ и СССР](../2-справочник/01-документы-ри-и-ссср.md), раздел 1 |
| **Фонд** | все бумаги одного учреждения (губернское правление, казённый раввин, канцелярия) |
| **Опись** | перечень дел фонда с заголовками; говорит, что дело есть, но не что в нём |
| **Дело** | одна папка или книга; **лист** — её страница (бывает «лист» и «оборот») |
| **Метрика**, метрическая книга | записи о рождениях, браках, разводах и смертях. Вели церковные приходы, у евреев — казённые раввины (с 1835 г.); с 1919–1920 гг. их заменили книги ЗАГС |
| **ЗАГС** | советские (и нынешние) органы записи актов гражданского состояния: рождение, брак, развод, смерть |
| **Ревизия**, ревизская сказка | перепись податного населения Российской империи (1719–1858, десять ревизий) для налогов и рекрутского набора. Сказка — список одного общества по дворам, с возрастом сейчас и «по прошлой ревизии». Подробно — [ревизская «лестница»](../2-справочник/01-документы-ри-и-ссср.md) |
| **Посемейный список** | список семей общества 1870-х годов с отсылкой к последней (X) ревизии 1858 г. |
| **Перепись 1897 года** | первая всеобщая перепись империи; показывает, где жили, а не где числились. Уцелела частично |
| **Указатель** | список фамилий или имён к делу, фонду или книге: говорит, что фамилия **там есть** и где искать. Бывает внутри дела (алфавит) или составлен сообществом |
| **Индекс** (база данных) | выписка из записи, сделанная людьми или программой (JewishGen, FamilySearch и др.): имя, год, место, иногда ссылка на кадр. Удобна для поиска, но ошибается. **Ни указатель, ни индекс не доказательство** — смотрите сам скан |
| **Скан**, **кадр** | скан — фотография листа документа; кадр — один снимок на плёнке или в PDF (номер кадра ≠ номер листа) |
| **Плёнка FamilySearch** | микрофильм, на который сняты одна или несколько книг; у каждой плёнки номер, у оцифрованной — номер **DGS** |
| **DGS** | Digital Group Number, номер оцифрованной плёнки на FamilySearch. По нему открывается просмотр кадров. Как дойти от каталога до кадра — [Архивы по странам](../2-справочник/07-архивы-по-странам.md), раздел «FamilySearch: каталог → плёнка → кадр» |
| **Полнотекстовый поиск** | поиск по словам внутри распознанного текста книг и газет (а не по готовому индексу) |
| **Распознавание (OCR)** | программа превращает изображение страницы в текст; в старых книгах часто ошибается, особенно в первой букве слова |
| **Wikimedia Commons** | открытое хранилище, куда выложены тысячи дел украинских архивов в PDF; поиска по фамилиям внутри нет |

## Люди, сословия, места

| Термин | Что это |
|---|---|
| **Сословие** | юридическое состояние человека в империи: дворяне, духовенство, купцы, мещане, крестьяне, цеховые и др. Это не происхождение: между мещанами и купцами переходили часто |
| **Мещанин** | городской житель податного сословия (ремесленник, мелкий торговец). Большинство евреев империи числились мещанами своего местечка |
| **Купец** (1-й, 2-й, 3-й гильдии) | сословие тех, кто объявил капитал и платил гильдейский сбор; могло меняться из года в год |
| **Приписка** | к какому обществу (городу, местечку, волости) человек **числился**. Ревизии и призыв шли по месту приписки, а жить человек мог совсем в другом месте. «Рашковскій мещ.» — мещанин местечка Рашков, а не фамилия |
| **Губерния, уезд, волость** | административное деление империи: губерния (крупный регион, примерно как нынешняя область или больше), уезд (часть губернии, как район), волость (сельская единица внутри уезда). Границы и подчинение менялись — смотрите на нужный год: [Места и карты](../2-справочник/06-места-и-карты.md) |
| **Местечко** (штетл) | небольшой город с большой долей еврейского населения в черте оседлости |
| **Черта оседлости** | западные губернии империи, где евреям разрешалось жить постоянно (с конца XVIII в. до 1917 г.) |
| **Казённый раввин**, раввинат | раввин, избранный общиной и утверждённый властями; вёл метрические книги евреев своего округа (раввината) |
| **Кантонист** | ребёнок, взятый в военную школу (1827–1856); многих крестили. Подробно — [Особые группы и смена имён](../2-справочник/04-особые-группы-и-смена-имён.md) |
| **Двойное имя** | у евреев часто было два имени (Мордко-Лейб); в документах могли записать одно из них |

## Метод

| Термин | Что это |
|---|---|
| **Маршрут поиска** | порядок работы руководства: вопрос → место → источник → индекс → скан → проверка → запись. Подробно — [Маршрут поиска](../1-поиск-с-ии/01-маршрут-поиска.md) |
| **Условие остановки** | заранее записанное, когда прекратить поиск по вопросу: «просмотрю все сохранившиеся годы 1875–1885 и остановлюсь» |
| **Охват** | что именно просмотрено: источник, годы, кадры, написания, способ. Без охвата «не нашёл» ничего не значит |
| **Контрольная запись** | имя или слово, которое в этом источнике точно есть. Если поиск не находит и её, сломан поиск, а не отсутствует человек |
| **Второй независимый признак** | кроме фамилии — ещё отчество, возраст, место, имена родных или занятие, взятые не из той же самой записи |
| **FAN** | Friends, Associates, Neighbors — поиск через окружение: друзей, компаньонов, соседей, свидетелей. Подробно — [Доказательность](../3-результат/01-доказательность.md), раздел 9 |
| **GPS** | Genealogical Proof Standard — пять условий, при которых вывод считается доказанным. Там же, раздел 3 |
| **Мост возрастов** | графа «по последней ревизии» в ревизской сказке: возраст того же человека в прошлой ревизии. По ней переходят от одной ревизии к предыдущей |
| **сМ** (сантиморганы) | единица длины общего участка ДНК у двух людей; по сумме сМ оценивают степень родства. Подробно — [ДНК](../2-справочник/15-днк.md) |
| **Эндогамия** | браки внутри замкнутой общины в течение многих поколений (у ашкеназских евреев и др.); из-за неё ДНК-совпадения кажутся ближе, чем есть |

## Статусы гипотез и связей

Во всём руководстве, в шаблонах и навыках — одна шкала: 🟢 подтверждена · 🟡 открыта / сильная версия · ⚪ не проверена / слабая · 🔴 снята. Что нужно для каждого статуса — [Доказательность](../3-результат/01-доказательность.md), раздел «Шкала статусов».

## Пометки в тексте руководства

В квадратных скобках после некоторых сведений стоит, насколько они проверены составителем:

| Пометка | Что значит |
|---|---|
| **[стр]** или **[открыто]** | сведения сверены на самой странице источника (на дату, указанную в разделе; обычно октябрь 2026 г.) |
| **[по выдаче]** или **[поиск]** | взято только из выдачи поисковика или из чужого обзора: саму страницу открыть не удалось. Перед важным решением откройте источник сами |
| **[не проверено]** | подтвердить по первоисточнику не удалось. Пользуйтесь как подсказкой, а не как фактом |
| **[опыт читателя]** | из материала, присланного читателем руководства: автор проверял это на живых запросах в своём проекте, составитель не повторял. Цифры — одного проекта; перед важным выводом проверьте сами. Пример — [Ложный ноль](../1-поиск-с-ии/09-ложный-ноль.md) |
| **(LRF)** | цифра из сводного списка Lost Russian Family, на самом сайте не проверялась |
| без пометки | общие сведения, опыт составителя или сведения, подтверждённые ссылкой рядом |

Своя пометка для ИИ-помощника: **[по памяти, проверить]** — так ИИ должен отмечать номер фонда, название села, дату или иной факт, который он назвал без открытого источника. Такое сведение — гипотеза до проверки.
