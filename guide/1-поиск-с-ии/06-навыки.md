# Навыки (skills) для Claude: что есть и как установить

О чём раздел: какие готовые навыки лежат в этом руководстве, когда каждый срабатывает и как их установить в Claude Code или в приложение Claude.

**Навык (skill)** — папка с инструкцией `SKILL.md` (и иногда справочниками, шаблонами, скриптами). Claude сам подгружает навык, когда задача подходит под его описание: вы пишете «прочитай этот скан метрической книги» — подключается навык чтения сканов со всеми приёмами и ловушками. Навыки повторяют методику этого руководства в форме, удобной для ИИ.

## 1. Какие навыки есть — по шагам маршрута

**Начало и организация работы**

| Навык | Когда срабатывает |
|---|---|
| `genealogy-intake` | первый разговор: «хочу найти предков», что известно, цель, файлы проекта, первый вопрос и план |
| `organizing-genealogy-research` | начало сессии, задания агентам, приём отчётов, «сохрани всё» |
| `research-session-handoff` | «сохрани всё», «продолжи с того места»: файл «Продолжать отсюда» |
| `orchestrating-genealogy-agents` | как разбить поиск на задания агентам, шаблон задания, темп, приём отчётов |
| `search-logic-navigator` | развилки поиска: «не нашёл», много однофамильцев, индекс спорит со сканом, тупик |

**Место и источник**

| Навык | Когда срабатывает |
|---|---|
| `identifying-places` | найти местечко или село, уезд и губернию на нужный год, смены границ и названий |
| `ukrainian-archives-on-commons` | дела украинских архивов на Wikimedia Commons и описи на Вікіджерелах |
| `soviet-era-records` | война, эвакуация, блокада, репрессии, советский ЗАГС |
| `tracing-emigrants-to-origin` | от документов США и Европы к местечку |
| `searching-pogrom-records` | погромы 1917–1922: базы жертв, получатели помощи, сироты, беженцы |
| `researching-jewish-cemeteries` | где похоронен, базы захоронений, чтение надгробия, перевод еврейской даты |

**Индекс и поиск по базам**

| Навык | Когда срабатывает |
|---|---|
| `using-community-surname-indexes` | сначала фамильный указатель (форум «Еврейские корни», JewishGen, JGFF), потом листание; реестр непрочитанных разделов |
| `searching-jewishgen` | базы JewishGen: поиск, лимит строк, чтение полей, переход к скану |
| `searching-familysearch-films` | плёнки FamilySearch: каталог → плёнка → кадр, границы книг, темп и капчи |
| `searching-yandex-archives` | Яндекс «Поиск по архивам»: операторы, написания, как читать результат |
| `searching-nli-jewish-press` | еврейские газеты в Национальной библиотеке Израиля |

**Скан и чтение**

| Навык | Когда срабатывает |
|---|---|
| `reading-archive-scans` | читать оцифрованные дела, оценить качество скана, усилить выцветшие чернила, карта тома |
| `tracing-revision-records` | идти вглубь по ревизским сказкам 1795–1858 |
| `reading-hebrew-yiddish-sources` | надгробия, ивритская часть метрик, подписи, газеты на идише |
| `dating-old-photos` | датировать старую фотографию по паспарту, одежде, ателье |
| `interpreting-jewish-family-photos` | что говорит еврейская семейная фотография об укладе и событии |

**Проверка и результат**

| Навык | Когда срабатывает |
|---|---|
| `verifying-genealogy-findings` | проверить находку, понять, значит ли что-то «не нашёл», перебор написаний, полнотекстовый поиск |
| `reconstructing-family-clusters` | нашли отца и детей — собрать пакет документов на семью и свести однофамильцев |
| `dna-matches-endogamy` | разбор ДНК-совпадений при эндогамии |
| `citizenship-by-descent-dossier` | собрать цепочку документов для гражданства по происхождению |
| `writing-family-history` | превратить находки в читаемый текст для родных |

Полный список с описаниями — [skills/README.md](../../skills/README.md).

Кроме навыков, в папке [agents/](../../agents/archive-mechanic.md) лежат два помощника-агента для Claude Code: `archive-mechanic` (массовая механическая работа со сканами) и `archive-transcriber` (внимательное чтение одного документа).

## 2. Как установить

**Claude Code — плагином (навыки и агенты сразу).** В Claude Code наберите:
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```

Вторая команда открывает карточку плагина в меню `/plugin`, где установку подтверждают. Пока репозиторий закрыт, команды сработают только у тех, у кого есть к нему доступ (Claude Code клонирует репозиторий через git с уже сохранёнными учётными данными GitHub). Обновления плагина сами не приходят: включите автообновление в `/plugin` → Marketplaces или обновляйте командой `/plugin marketplace update genealogy-guide-ru` (code.claude.com/docs, «Host and maintain a marketplace»).

**Claude Code — вручную.** Скопируйте папки из `skills/` в `~/.claude/skills/`, файлы из `agents/` — в `~/.claude/agents/`.

**Claude.ai и приложение Claude.** На платных планах (Pro, Max, Team, Enterprise) плагин можно добавить и там: меню Customize → Plugins → Add → Add marketplace, затем адрес репозитория (для закрытого репозитория нужен доступ к нему через GitHub). Отдельный навык можно загрузить и без плагина: заархивируйте папку навыка целиком (ZIP, внутри папка с `SKILL.md`) и добавьте в Customize → Skills; для навыков нужно включённое выполнение кода (support.claude.com, статьи «Use plugins in Claude» и «Use skills in Claude»). Скрипты из папок `scripts/` в веб-версии могут не запускаться (например, без доступа к сети) [не проверено].

**Другие помощники (Gemini, ChatGPT и др.).** Навыки — обычные текстовые файлы. Можно приложить `SKILL.md` нужного навыка к разговору или дать ссылку на него и попросить работать по этой инструкции.

## 3. Ограничения

- Навыки не проходят капчи и не входят в аккаунты — это делает человек.
- Навыки не предлагают писать в архивы как шаг поиска: сначала онлайн-пути. Решение о письме — за человеком ([Запросы и письма](../2-справочник/20-запросы-и-письма.md)).
- Сайты меняются: приёмы проверены в сентябре–октябре 2026 г.
