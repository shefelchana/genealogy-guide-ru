# Навыки (skills) для Claude: что есть и как установить

О чём раздел: какие готовые навыки лежат в этом руководстве, когда каждый срабатывает и как их установить в Claude Code или в приложение Claude.

**Навык (skill)** — папка с инструкцией `SKILL.md` (и иногда справочниками, шаблонами, скриптами). Claude сам подгружает навык, когда задача подходит под его описание: вы пишете «прочитай этот скан метрической книги» — подключается навык чтения сканов со всеми приёмами и ловушками. Навыки повторяют методику этого руководства в форме, удобной для ИИ.

## 2. Как установить

**Claude Code — плагином (навыки и агенты сразу).** В Claude Code наберите:
```
/plugin marketplace add shefelchana/genealogy-guide-ru
/plugin install genealogy-guide-ru@genealogy-guide-ru
```

Вторая команда открывает карточку плагина в меню `/plugin`, где установку подтверждают. Обновления плагина сами не приходят: включите автообновление в `/plugin` → Marketplaces или обновляйте командой `/plugin marketplace update genealogy-guide-ru` (code.claude.com/docs, «Host and maintain a marketplace»).

**Claude Code — вручную.** Скопируйте папки из `skills/` в `~/.claude/skills/`, файлы из `agents/` — в `~/.claude/agents/`.

**Claude.ai и приложение Claude.** На платных планах (Pro, Max, Team, Enterprise) плагин можно добавить и там: меню Customize → Plugins → Add → Add marketplace, затем адрес репозитория `shefelchana/genealogy-guide-ru`. Отдельный навык можно загрузить и без плагина: заархивируйте папку навыка целиком (ZIP, внутри папка с `SKILL.md`) и добавьте в Customize → Skills; для навыков нужно включённое выполнение кода (support.claude.com, статьи «Use plugins in Claude» и «Use skills in Claude»). Скрипты из папок `scripts/` в веб-версии могут не запускаться (например, без доступа к сети) [не проверено].

**Другие помощники (Gemini, ChatGPT и др.).** Навыки — обычные текстовые файлы. Можно приложить `SKILL.md` нужного навыка к разговору или дать ссылку на него и попросить работать по этой инструкции.

## 3. Ограничения

- Навыки не проходят капчи и не входят в аккаунты — это делает человек.
- Навыки не предлагают письмо в архив вместо поиска: сначала онлайн-пути. Письмо — адресное, с точным шифром; решение и отправка — за человеком; составить текст ИИ поможет, если вы попросите ([Запросы и письма](../2-справочник/20-запросы-и-письма.md)).
- Сайты меняются: приёмы проверены в сентябре–октябре 2026 г.
